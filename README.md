# Cloud Monitoring & Alerting System (AWS)

This project implements a serverless monitoring pipeline using AWS Lambda, CloudWatch, and SNS to detect anomalies and trigger real-time alerts.

## Features
- Event-driven monitoring using AWS Lambda
- Log tracking and metrics with CloudWatch
- Real-time alerting using SNS
- Basic system observability and anomaly detection

## Tech Stack
- AWS Lambda
- Amazon CloudWatch
- Amazon SNS
- Linux CLI

## Overview
The system processes logs and system events to monitor behavior and trigger alerts when anomalies are detected. It demonstrates event-driven architecture and cloud-based monitoring concepts.
